# 钢铁前线 - 抖音小游戏发布包

## 包内容

```
build/douyin/
├── game.json              # 抖音小游戏配置（横屏、网络超时等）
├── project.config.json    # 开发者工具项目配置（请修改appid）
├── configs/               # 游戏配置JSON（国家、焦点、科研、商店等）
└── src/                   # 编译后的JS源码
```

## 发布步骤

### 方式一：Cocos Creator 构建发布（推荐，完整可运行包）

1. 使用 Cocos Creator 3.x 打开项目根目录
2. 菜单：**扩展 → 扩展编辑器 → 抖音小游戏发布插件**（如未安装请先从 Cocos 商店安装）
3. 菜单：**项目 → 构建发布**
4. 平台选择：**抖音小游戏**
5. 配置参数：
   - 应用ID（appid）：填入你在抖音开放平台申请的小游戏ID
   - 设备方向：横屏（landscape）
   - 初始场景：MainScene
6. 点击**构建** → 构建完成后点击**发布**
7. 使用抖音开发者工具打开 `build/douyin` （或Cocos输出目录）进行预览/上传

### 方式二：源码审核包（本包用途）

本目录包含：
- ✅ 所有游戏逻辑源码（已编译为CommonJS JS）
- ✅ 抖音登录系统实现 (`src/platform/auth/`)
- ✅ 入侵系统实现 (`src/core/simulation/invasion_system.js`)
- ✅ 用户隔离存储 (`src/platform/storage/`)
- ✅ 游戏配置数据 (`configs/`)
- ✅ 必要配置文件（game.json / project.config.json）

**注意**：本包未包含 Cocos 引擎运行时和场景资源，完整运行需通过 Cocos Creator 构建。

### 核心技术指标

- ✅ **确定性仿真**：相同输入必产生相同结果（99个测试验证）
- ✅ **双人对战同步**：基于状态哈希的帧同步验证
- ✅ **10Hz tick**：100ms一步，支持1/2/5倍速
- ✅ **横屏适配**：1280×720 设计分辨率

## appid 配置

编辑 `project.config.json`，将 `appid` 字段替换为你的抖音小游戏 appid：

```json

}
```
