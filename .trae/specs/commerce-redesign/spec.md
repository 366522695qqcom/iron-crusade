# 商业化重设计 Spec（commerce-redesign）

> 变更类型：商业化策略调整
> 影响文档：[PROJECT.md](../../../PROJECT.md) 第 8 章
> 影响代码：`src/platform/ads/`、`optimize-for-launch` spec 的 B.2 已实现代码
> 用户核心原则：**全面不卖数值、局内不卖任何东西、局外通过外观/内容广告让玩家看广告**

## Why

现有商业化设计（PROJECT.md 8.1 + optimize-for-launch B.2）存在方向偏差：
1. **局外卖数值**：每日补给箱给资源、离线收益双倍给数值，违反「不卖数值」原则
2. **局内卖数值**：单机局内「工厂加速建造」「双倍工业产出」直接卖数值（建造立即完成、工业 buff），「刷新焦点卡」卖局内便利，违反「局内的东西尽量不要卖」原则
3. **局外广告形式单一**：仅靠资源奖励驱动，缺乏长线外观/内容变现抓手
4. **局内/局外边界模糊**：未明确区分局内（无广告）、局外（不卖数值、只卖外观/内容）两类场景

本次重设计确立「**全面不卖数值、局内不卖任何东西、局外通过外观/内容广告变现**」的商业化边界：删除全部卖数值广告（含局外每日补给箱/离线双倍、局内工厂加速/双倍产出/焦点刷新），将变现重心全部移至局外的外观/皮肤与内容解锁两类非数值广告，让玩家在局外看广告。

## What Changes

### REMOVED（删除全部卖数值/卖局内广告）

**局外卖数值广告**：
- **删除**「每日补给箱」广告位（看广告领随机资源）— 违反「不卖数值」
- **删除**「离线收益双倍」广告位（看广告使离线资源翻倍）— 违反「不卖数值」
- **删除** `src/platform/ads/daily_supply_box.ts`、`src/platform/ads/offline_double.ts`（optimize-for-launch B.2 已实现代码）

**局内卖数值/卖便利广告**：
- **删除**「工厂加速建造」广告位（看广告 → 建造立即完成）— 卖数值，违反「不卖数值」+「局内尽量不卖」
- **删除**「双倍工业产出（1 小时）」广告位（看广告 → 工业 buff）— 卖数值，违反「不卖数值」+「局内尽量不卖」

## ADDED Requirements

### Requirement: 局外外观/皮肤系统

系统 SHALL 提供局外外观/皮肤解锁机制，通过观看激励视频广告解锁纯装饰内容：

- 解锁对象：国家主题色、地图皮肤、UI 主题、部队图标等纯装饰内容
- 严格不影响任何游戏数值（不给资源/政治点/时间加速/战斗力等）
- 解锁后永久生效，所有存档可用
- 解锁入口在局外商店界面（主菜单 → 商店 → 外观）
- 单机模式可用；联机模式商店入口隐藏（联机无广告）

#### Scenario: 解锁外观
- **WHEN** 玩家在局外商店点击某外观的「看广告解锁」按钮
- **THEN** 播放激励视频广告
- **AND** 广告观看完成后，该外观永久解锁并标记为已拥有
- **AND** 玩家可在设置中切换已解锁的外观

#### Scenario: 联机模式隐藏商店
- **WHEN** 玩家处于联机对局或联机大厅
- **THEN** 商店入口隐藏，无法触发任何广告

### Requirement: 局外内容解锁

系统 SHALL 提供局外内容解锁机制，通过观看激励视频广告解锁游戏内容：

- 解锁对象：新剧本、新国家、新焦点树分支等内容
- 内容解锁为「可用性」解锁，非数值优势（解锁后该内容与其他内容平衡一致）
- 解锁后永久生效，所有存档可用
- 解锁入口在局外商店界面（主菜单 → 商店 → 内容）
- 单机模式可用；联机模式商店入口隐藏

#### Scenario: 解锁新国家
- **WHEN** 玩家在局外商店点击某国家的「看广告解锁」按钮
- **THEN** 播放激励视频广告
- **AND** 广告观看完成后，该国家永久解锁
- **AND** 玩家在新建存档时可选该国家

### Requirement: 局外商店统一入口

系统 SHALL 提供局外商店作为外观与内容解锁的统一入口：

- 商店位于主菜单（非对局内），含「外观」「内容」两个分页
- 商店不展示任何数值奖励商品
- 商店所有商品仅可通过「看广告」解锁，无 IAP（沿用无 IAP 原则）
- 联机模式下商店入口隐藏

#### Scenario: 进入商店
- **WHEN** 玩家在主菜单点击「商店」
- **THEN** 显示商店界面，含外观与内容两个分页
- **AND** 每个商品显示「看广告解锁」按钮与已解锁状态

## MODIFIED Requirements

### Requirement: 商业化广告位原则（局内/局外边界）

**原需求**（PROJECT.md 8.1）：单机模式广告位含工厂加速、焦点刷新、双倍产出、剧本解锁、每日补给箱、离线双倍、结算插屏、主界面 Banner。

**修改后**：按场景二分类明确边界，**局内全面无广告**：

| 场景 | 广告规则 |
|---|---|
| 局内（单机对局 + 联机对局） | **无任何广告**（单机与联机一致，对局中不出现任何广告入口；工厂加速/焦点刷新/双倍产出/剧本解锁全部删除） |
| 局外（主菜单/结算/商店/存档管理） | **不卖任何数值**，仅外观/皮肤解锁 + 内容解锁 + 结算插屏 + 主界面 Banner |

#### Scenario: 局内无任何广告
- **WHEN** 玩家处于单机对局或联机对局
- **THEN** 任何广告入口均不展示，广告 API 禁用（工厂不提供加速按钮、焦点不提供刷新按钮、生产不提供双倍按钮）

#### Scenario: 局外不卖数值
- **WHEN** 玩家在局外商店浏览商品
- **THEN** 所有商品均为外观或内容解锁，无任何资源/政治点/时间加速等数值奖励
