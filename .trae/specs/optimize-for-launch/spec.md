# 项目优化方案 Spec（optimize-for-launch）

> 变更类型：大型设计优化
> 影响文档：[PROJECT.md](../../../PROJECT.md)、[技术设计文档.md](../../技术设计文档.md)
> 用户明确约束：**保留真实国界地图**（不切换为全抽象地图），其余优化方案全部采纳

## Why

现有设计完成度高、核心方向准确，但硬核 HOI4 策略深度与抖音小游戏审核规则、用户心智、碎片化场景存在错位。优化围绕「保上线、降门槛、控成本、留灵魂」展开，在保留 HOI4 核心经营策略质感的前提下，最大程度适配抖音平台的审核规则、用户习惯与成本约束。

核心矛盾：
1. **审核高危（生死级）**：意识形态标签 + 战争题材强暗示，触碰抖音审核红线
2. **平台适配错位**：近 10 个系统堆叠导致上手门槛过高；长期存档制与碎片化打开习惯冲突

> 注：落地成本（实时帧同步 / 服务器成本）相关优化暂不在本 spec 范围内，保持现有联机方案设计。

## What Changes

### S 级（生死线 · 审核合规）

- **MODIFIED** 世界观脱敏：删除「法西斯/共产主义/民主」意识形态标签，替换为架空发展路线（工业集权线 / 公社共治线 / 联邦共和线）
- **MODIFIED** 战争属性弱化：「宣战/占领/伤亡」替换为「区域争端/管控/撤离」
- **MODIFIED** 历史强暗示弱化：领袖、装备、国家代号仅保留风格，删除可直接对应真实历史的强关联元素
- **MODIFIED** 玩法重心倾斜：工业建设、资源经营作为核心卖点，战争作为可选冲突玩法
- **保留** 真实国界地图方案（用户明确要求不切换为全抽象地图），保留抽象备选包作为审核降级（见附录 D.1.8）

### A 级（MVP 核心 · 玩法体验）

- **ADDED** 双模式分层：快速对局模式（10-15 分钟单局）+ 经典存档模式（现有长期存档玩法）
- **ADDED** 助理模式：新手默认开启，自动分配空闲工厂 / 调度补给 / 布防前线，玩家仅做核心决策；老手可关闭
- **ADDED** 阶梯式新手引导：按日拆解系统（Day1 资源与工厂 → Day2 生产与部署 → Day3 作战与外交）
- **ADDED** 单次会话目标：每次打开游戏提示「今日可完成 1 个焦点 + 升级 2 座工厂」
- **ADDED** 关键事件召回：焦点完成 / 工厂空闲 / 遭遇争端时通过抖音消息推送召回用户

### B 级（体验变现）

- **ADDED** 每日任务体系：配合长期存档，每日建造 / 生产 / 作战小任务，奖励政治点 / 资源
- **MODIFIED** 广告位温和化：新增「每日补给箱」（看广告领随机资源）、「离线收益双倍」
- **MODIFIED** 联机奖励回流强化：联机胜利奖励发放到单机存档（沿用 PROJECT.md 5.3 现有设计）

### C 级（进阶内容 · 后期）

- **保留** 实时帧同步联机方案（技术设计文档第 5 章 + 附录 B/C），按原里程碑推进
- **保留** 完整国策树、多国家剧本作为后期扩充内容

### 技术落地优化

- **MODIFIED** 包体与性能管控：地图保留真实国界矢量但严控简化阈值；UI 以代码绘制为主；主包预留 ≥1MB 冗余；非核心资源全分包
- **MODIFIED** 确定性能力前置：单机阶段严格落地定点数 / 有序容器 / 固定 tick / CI 哈希校验，为后续联机铺路

## ADDED Requirements

### Requirement: 双模式分层

系统 SHALL 提供两种游戏模式，覆盖不同用户群体：

- **快速对局模式**：单局 10-15 分钟，仅保留资源-工厂-战斗核心系统，预设建筑与发展路线，降低决策成本，作为抖音碎片化场景的新手入口
- **经典存档模式**：保留现有完整长期存档玩法（PROJECT.md 第 5 章），面向核心策略玩家，从快速模式导流

#### Scenario: 新玩家首次进入
- **WHEN** 新玩家首次打开游戏
- **THEN** 默认进入快速对局模式，10-15 分钟可完成一局
- **AND** 完成首局后引导尝试经典存档模式

#### Scenario: 模式切换
- **WHEN** 玩家在主界面切换模式
- **THEN** 快速对局与经典存档存档隔离，互不影响

### Requirement: 助理模式

系统 SHALL 提供助理模式，降低操作门槛：

- 新手默认开启，老手可手动关闭全手动操作
- 助理功能：自动分配空闲工厂、自动调度补给、自动布防前线
- 玩家仅做焦点、科研、总攻等核心决策
- 助理模式与联机 AI 接管（附录 B.2）复用同一行为树核心，但参数不同（助理更保守）

#### Scenario: 助理自动分配空闲工厂
- **WHEN** 助理模式开启且存在空闲民用工厂
- **THEN** 助理按附录 B.2 的 Factory 决策逻辑自动分配到建造队列最高优先级项
- **AND** UI 显示「助理已分配 X 座工厂」提示，玩家可撤销

#### Scenario: 玩家关闭助理
- **WHEN** 玩家在设置中关闭助理模式
- **THEN** 所有自动分配停止，工厂空闲提醒系统（3.3.3）恢复生效

### Requirement: 阶梯式新手引导

系统 SHALL 提供按日拆解的阶梯式新手引导，避免一次性信息过载：

- Day1：资源与工厂（资源采集、工厂铺设基础）
- Day2：生产与部署（装备生产、部队部署）
- Day3：作战与外交（拉线攻势、外交按钮）

#### Scenario: 新手 Day1 解锁
- **WHEN** 新玩家完成首局快速对局
- **THEN** 解锁 Day1 引导任务（建造 1 座民厂、采集 100 钢铁）
- **AND** Day2/Day3 功能锁定，完成 Day1 后解锁

### Requirement: 单次会话目标

系统 SHALL 在每次打开游戏时提示单次会话目标，适配碎片化场景：

- 目标示例：「今日可完成 1 个焦点 + 升级 2 座工厂」
- 目标基于玩家当前存档进度动态生成
- 完成目标给予额外奖励

#### Scenario: 显示会话目标
- **WHEN** 玩家打开游戏进入主界面
- **THEN** 顶部显示今日会话目标卡片
- **AND** 目标完成后卡片变绿，发放奖励

### Requirement: 关键事件召回推送

系统 SHALL 通过抖音消息推送在关键事件发生时召回用户：

- 触发场景：焦点完成、工厂长时间空闲、遭遇区域争端
- 推送渠道：抖音订阅消息（需用户授权）
- 推送频率限制：每日 ≤2 条，避免打扰

#### Scenario: 工厂空闲召回
- **WHEN** 玩家离线且工厂空闲超过 30 分钟
- **THEN** 触发抖音订阅消息推送「3 座工厂空闲，回游戏分配任务」
- **AND** 玩家点击推送直接进入对应工厂界面

### Requirement: 每日任务体系

系统 SHALL 提供每日任务体系，配合长期存档培养日活习惯：

- 每日 3 个小任务：建造类、生产类、作战类各 1
- 完成奖励：政治点 / 资源 / 临时 buff
- 任务每日 0 点刷新，未完成不累计

#### Scenario: 每日任务刷新
- **WHEN** 北京时间 0:00
- **THEN** 刷新 3 个每日任务，清空昨日未完成项
- **AND** 主界面显示任务进度条

## MODIFIED Requirements

### Requirement: 世界观脱敏

**原需求**（PROJECT.md 4.1/4.2/4.3）：国家带意识形态标签（法西斯/共产主义/民主），阵营对应历史原型。

**修改后**：
- 删除「法西斯/共产主义/民主」意识形态标签
- 替换为架空发展路线：工业集权线 / 公社共治线 / 联邦共和线
- 发展路线为国家可选择的政策方向，非固有属性
- 阵营名称进一步架空，弱化与历史原型的强关联

#### Scenario: 国家发展路线选择
- **WHEN** 玩家选择国家发展路线
- **THEN** 可选工业集权线 / 公社共治线 / 联邦共和线，三选一
- **AND** 路线影响焦点树分支与 buffs，但无意识形态敏感词

### Requirement: 战争属性弱化

**原需求**（PROJECT.md 3.7/3.9/6）：宣战、占领、伤亡等战争术语。

**修改后**：
- 「宣战」→「发起区域争端」
- 「占领」→「管控」
- 「伤亡」→「撤离」
- 「战争支持度」→「争端决心」
- 申报与宣传主打「策略经营」定位，弱化战争对抗标签

#### Scenario: 发起区域争端
- **WHEN** 玩家对敌对国家发起争端
- **THEN** UI 显示「发起区域争端」按钮（原「宣战」）
- **AND** 结算界面显示「管控区域」与「部队撤离」（原「占领」与「伤亡」）

### Requirement: 玩法重心倾斜

**原需求**（PROJECT.md 3.1）：资源-工业-生产-战争并重。

**修改后**：
- 工业建设、资源经营作为核心卖点
- 战争作为可选冲突玩法，非强制
- 新手引导优先教学工业与资源，战斗延后

### Requirement: 地图方案（保留真实国界）

**原需求**（PROJECT.md 4.5 + 附录 D.1）：照搬真实世界国界。

**修改后**（用户明确要求保留）：
- 主包继续采用真实国界地图方案（附录 D.1）
- 保留 `map_abstract.bin` 抽象备选包（附录 D.1.8）作为审核降级
- 配合题材脱敏降低整体审核风险
- 提审前预审，若真实国界被拒则切换抽象包

### Requirement: 商业化广告位温和化

**原需求**（PROJECT.md 8.1）：激励视频加速、刷新焦点、双倍产出、解锁剧本、插屏、Banner。

**修改后**：
- 保留现有广告位
- 新增「每日补给箱」：看广告领随机资源（每日 1 次）
- 新增「离线收益双倍」：看广告使离线期间资源产出翻倍
- 严格执行联机无广告规则（沿用 PROJECT.md 8.2 现有设计）

### Requirement: 开发里程碑重排

**原需求**（PROJECT.md 10 / 技术设计文档 10）：M1 单机 → M2 系统补全 → M3 实时联机 → M4 联机存档 → M5 商业化 → M6 审核。

**修改后**：
- M1 单机核心循环（含助理模式 + 快速对局模式 + 新手引导）
- M2 系统补全 + 每日任务 + 广告位温和化
- M3 实时联机 MVP（沿用原设计：信令服务器 + Host 权威帧同步 + 1v1 + drop in/out + AI 接管）
- M4 联机存档（沿用原设计：Host 存档 + 服务器快照 + host 迁移）
- M5 商业化完善
- M6 审核（含真实国界预审 + 抽象包备选）

### Requirement: 包体与性能管控

**原需求**（技术设计文档 7.3）：主包 <4MB。

**修改后**：
- 地图保留真实国界矢量但严控简化阈值（附录 D.1）
- UI 以代码绘制为主，严控纹理资源量
- 主包预留 ≥1MB 冗余空间（实际目标 ≤3MB）
- 非核心国家、剧本、美术资源全部分包加载

### Requirement: 确定性能力前置

**原需求**（技术设计文档 2 + 附录 C）：联机时启用。

**修改后**：
- 单机阶段即严格落地定点数 / 有序容器 / 固定 tick / CI 哈希校验
- 为联机阶段铺路，避免重构成本
